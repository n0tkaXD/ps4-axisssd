# Регистрация игр с SSD на PS4 (личный стенд)

Внутренний README для себя. Не для публикации.

## Что это
Скрипт отправляет на PS4 payload, который проходит по папкам `PKG` на USB-дисках
и регистрирует новые `.pkg` по символической ссылке, без копирования на внутренний диск.

## Что нужно
- PS4 с GoldHEN (загружен через BD-JB / Lapse, прошивка 12.00)
- BinLoader Server включён в настройках GoldHEN
- SSD (exFAT) с папкой `PKG` в корне: `/mnt/usb0/PKG`
- Mac: Terminal + `curl`, `nc`, `python3` (есть по умолчанию)

## Как пользоваться (Mac)
1. Распаковать `ps4_register_mac.zip` в одну папку.
2. Вписать IP PS4 в `ps4_ip.txt` (или скрипт спросит сам и запомнит).
3. Положить `.pkg` в `PKG` на SSD.
4. Двойной клик по `ps4_register.command`.
5. Перезагрузить PS4 и загрузить GoldHEN снова — новые игры появятся в меню.

Windows: то же самое через `ps4_register.ps1` (правый клик → выполнить с PowerShell).
**Windows-версия не проверена.**

## Что проверено
- Регистрация и запуск EmuSuNi с SSD (после перезагрузки и без неё — оба варианта наблюдались).
- Регистрация и запуск homebrew NP2kai: запуск требует перезагрузки.
- Удаление зарегистрированной игры через меню не обнуляет файл на SSD, если он защищён атрибутом «только чтение». Сейчас защита отключена (она ломала запуск), поэтому удалять через меню файлы на SSD нельзя.

## Что НЕ проверено / известно
- Windows-скрипт.
- Большие игры (десятки ГБ): скорость, стабильность.
- Патчи и DLC — не поддерживаются.
- Защита от удаления через меню для запуска без сбоев — не решена.

## Риски
- Payload работает с правами root и меняет системную регистрацию. Ошибка может уронить систему.
- База игр (`/system_data/priv/mms/app.db`) меняется системой при регистрации. Бэкап от 2026-10-21 лежит в `backups/db_20261021_045618/`.
- Отключение SSD во время игры может повредить файлы или зависнуть игру.
- Не запускать сканеры по порту 9090 — это выключает BinLoader.

## Откат
- База: вернуть `app.db` и `addcont.db` из `backups/db_20261021_045618/` через FTP (`/system_data/priv/mms/`), при закрытых играх, с последующей перезагрузкой.
- Отдельная игра: удалить через меню, но только если её файл на SSD не защищён (см. выше) — иначе файл обнулится. Сначала скопировать PKG на Mac.

## Структура
- `ps4_register.command` — скрипт для Mac
- `ps4_register.ps1` — скрипт для Windows
- `ps4_ip.txt` — IP PS4
- `proto/build/ifusb_scan.bin` — payload (регистрация всех новых игр в `PKG`)
- `tools/send_payload.py` — отправка payload на порт 9090
